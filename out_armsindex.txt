Question: What is the EasyLanguage syntax for the ArmsIndex function (TRIN)? How is it called, what parameters does it take, and what does it return? Provide the exact function call syntax.
============================================================

The exact EasyLanguage syntax for the Arms Index (TRIN) function is:
ArmsIndex(AdvIssues, AdvVolume, DecIssues, DecVolume)1
Parameters:
AdvIssues (Numeric): Specifies the advancing issues price data series. This is typically the Close of Data1 (referencing the close of an advancing issues symbol like $ADV)2.
AdvVolume (Numeric): Specifies the advancing volume data series. This is typically the Volume of Data12.
DecIssues (Numeric): Specifies the declining issues price data series. This is typically the Close of Data2 (referencing the close of a declining issues symbol like $DECL)2.
DecVolume (Numeric): Specifies the declining volume data series. This is typically the Volume of Data22.
Return Value: The function returns a Double representing the numeric value of the Arms Index for the current bar1.
How it is called: Because the function requires both advancing and declining data sets, it must be used on a multi-data chart where both sets of symbols are present3. It is called by passing the specific price and volume data series components to the function and assigning the result to a variable4.
Here is a standard example of how to call the function: Value1 = ArmsIndex(Close of Data1, Volume of Data1, Close of Data2, Volume of Data2);
It is also commonly smoothed using a moving average, which can be called like this: Value1 = Average(ArmsIndex(Close of Data1, Volume of Data1, Close of Data2, Volume of Data2), 21);4
